# WeatherApp

A small weather app made using WPF.
<br>Its purpose is showing proficiency with WPF and application of MVVM pattern.

This app is basically a wrapper for [wttr.in](https://wttr.in) ([GitHub](https://github.com/chubin/wttr.in)) where it is possible to save multiple locations for easier access.

## Installation

### Portable App

- Download the zip-file from the [releases page](https://github.com/MerlinDeadleft/WeatherApp/releases)
- Unzip to any directory you want (if the appl is placed in a folder called "Program Files" it needs to be run as an administrator)
- Run WeatherApp.exe

### Self Compiled

- Download the source code
- Open the project in the IDE of your choice
- Build the project
